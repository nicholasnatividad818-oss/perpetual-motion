# perpetual-motion

3D visualization of the digital-root doubling wheel **1-2-4-8-7-5** and the numbers that refuse it: **3, 6, and 9**.

Open `index.html` in a browser. Drag to orbit. Scroll to approach.

- Cyan torus: motion (powers of two, reduced to one digit)
- Ember icosahedra: 3 and 6, orbiting off the wheel
- Gold octahedron: 9 on the still axis

This is modular arithmetic made visible, not a free-energy machine. The name is a joke the wheel tells on itself: the circuit walks forever. It does not do work for free.
